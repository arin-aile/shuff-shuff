# SHUFF SHUFF

Playing Card Salon — interactive card scattering and suit drawing prototype.

Move your pointer across the deck to scatter cards. Click SHUFF to enter the drawing screen. Drag Playing Card Salon left and right to move the card-edge wave.

Open `index.html` directly in a browser. No build or dependencies are required.

## Updates

Replace `index.html` with the updated prototype and commit to `main`. GitHub Pages publishes from the repository root.
